Flujo de trabajo

Proceso realizado durante el laboratorio.

1

Clonar

Se obtiene una copia local del repositorio mediante git clone.

2

Crear rama

Cada colaborador trabaja en una rama independiente de main.

3

Modificar

Se realizan los cambios correspondientes dentro del proyecto.

4

Commit & Push

Los cambios son registrados y enviados al repositorio remoto.

5

Pull Request

Se solicita integrar los cambios realizados hacia la rama principal.
